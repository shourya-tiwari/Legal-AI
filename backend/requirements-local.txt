# ---------------------------------------------------------------------------
# OPTIONAL: in-process self-hosted neural models (Class A/B), no Docker.
#
#   sentence-transformers -> `local-embed-neural` / `local-rerank-neural`
#                            (fallback for the TEI servers)
#   transformers + sentencepiece -> `local-nli` (Phase 6 Verifier NLI head,
#                            app/services/model_router/providers/nli_local.py)
#   gliner               -> `local-ner` (Phase 6 zero-shot NER,
#                            app/services/model_router/providers/gliner_local.py)
#
# The router prefers a dedicated TEI server (`local-embed-remote` /
# `local-rerank-remote`, EMBEDDING_BASE_URL / RERANKER_BASE_URL) when one is
# configured, and drops to the Class A hashing / lexical approximations when
# neither is present. The NLI head has no server option -- it's this or the
# lexical-overlap fallback in app/agents/verifier.py.
#
# Pulls PyTorch -- BUT if a GPU torch build is already importable (e.g. an
# existing ~/.local torch+cuXXX picked up via `python -m venv --system-site-
# packages`), pip reuses it and sentence-transformers runs on the GPU
# automatically. See scripts/setup_venv.sh.
#
#   pip install -r requirements-local.txt
#
# Recommended models for the in-process path (docs/v2/MODEL_STACK.md):
#   EMBEDDING_MODEL   -> BAAI/bge-m3            (1024-d, multilingual; matches the TEI server)
#   RERANKER_MODEL    -> BAAI/bge-reranker-v2-m3
#   (BAAI/bge-small-en-v1.5 + cross-encoder/ms-marco-MiniLM-L-6-v2 are the
#    lighter CPU-friendly choices and remain the app/config.py defaults.)
# ---------------------------------------------------------------------------
